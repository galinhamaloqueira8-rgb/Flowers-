# Flowers — Reviver Chat

Bot Discord que, após 30 minutos sem mensagens, envia uma pergunta aleatória para movimentar o chat.

Configure `DISCORD_TOKEN` como variável secreta na hospedagem.

No Discord Developer Portal, ative **Message Content Intent** em Bot > Privileged Gateway Intents.

Comandos:
- `npm install`
- `npm start`

Nunca coloque seu token diretamente no GitHub.
